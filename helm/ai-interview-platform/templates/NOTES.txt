1. Watch the rollout:

   kubectl -n {{ .Release.Namespace }} get pods -l app.kubernetes.io/instance={{ .Release.Name }} -w

   The middleware runs Flyway migrations during startup, so its first pod can take
   up to {{ mul .Values.middleware.probes.startup.periodSeconds .Values.middleware.probes.startup.failureThreshold }}s to pass its startup probe.

2. Reach the application:

{{- if .Values.ingress.enabled }}
   http{{ if .Values.ingress.tls.enabled }}s{{ end }}://{{ .Values.ingress.host }}

   An ALB takes 2-3 minutes to become active. Check progress with:
     kubectl -n {{ .Release.Namespace }} describe ingress {{ include "aip.fullname" . }}
{{- else }}
   No Ingress is enabled. Port-forward instead:

     kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "aip.componentName" (dict "root" . "component" "frontend") }} 3000:{{ .Values.frontend.service.port }}
     kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "aip.componentName" (dict "root" . "component" "middleware") }} 8080:{{ .Values.middleware.service.port }}

   Then open http://localhost:3000
{{- end }}
